# Visual rubric

ให้คะแนน 1–5 ต่อหัวข้อ Agent 10 ใช้ self-review และ QQ ให้คะแนนอิสระ เกณฑ์พร้อมส่งผู้ใช้คือ
**ทุกหัวข้ออย่างน้อย 4/5 และไม่มี major defect** ส่วน factual gate ต้องผ่าน 100% แยกต่างหาก

| หัวข้อ | เกณฑ์ผ่าน |
|---|---|
| Visual hierarchy | เห็นสารหลักก่อน เงื่อนไข/ระดับสำคัญเป็นลำดับถัดไป รายละเอียดรองไม่แย่งสายตา |
| Composition | grid, margin และพื้นที่หายใจสมดุล ไม่มีพื้นที่ตายหรือองค์ประกอบทับกัน |
| Typography | ภาษาไทยครบ ไม่แตก ไม่ล้น ขนาด น้ำหนัก และระยะบรรทัดแยกชั้นชัด |
| Legibility | อ่านได้ทั้งภาพจริงและ preview ย่อ 50% ป้ายสำคัญไม่ต้องเดา |
| Contrast & color | contrast พอ สีมีความหมายคงที่ และไม่ใช้สีเป็นสัญญาณเพียงอย่างเดียว |
| Clarity | ลดเส้น กล่อง และคำที่ไม่ช่วย โดยไม่ตัด evidence ที่ brief บังคับ |
| Style consistency | สอดคล้อง reference ที่อนุมัติ แต่ไม่คัด facts จากภาพอ้างอิง |
| Finish | crop, spacing, ขอบ, ลูกศร, พื้นหลัง และ export เรียบร้อย ไม่มี artifact หรือรอยลบ |

ตรวจเพิ่มตามชนิดภาพ:

- กราฟ/decision map: ลูกศรและสีต้องสื่อ “เงื่อนไข” ไม่ใช่การทำนาย และห้ามบังแท่ง/ระดับ
- indicator: แผงราคาและ indicator ต้องแยกชั้น อ่านค่าได้ และ decorative edit ห้ามเปลี่ยนเส้น
- calendar: ลำดับแถวและข้อความเดิมต้องคงอยู่ แหล่งที่มาต้องอ่านได้โดยไม่บังตาราง

Major defect ได้แก่ factual mismatch, ข้อความขาด/ล้น, overlap ที่ทำให้อ่านผิด, contrast ต่ำจนอ่านไม่ได้,
artifact ชัดเจน หรือภาพที่ route ความหมายตลาดต่างจาก brief
