# Locale Pack — th-TH Financial Editorial

แพ็กกฎเฉพาะภาษาไทย ใช้**คู่กับ** `edit-financial-language` (สกิลกลางไม่มีกฎภาษาอยู่ในตัว)

ข้อมูลกฎที่เป็นค่าตายตัวอยู่ที่ `Repo/language/locales/th-TH/` — **ไฟล์นั้นคือความจริง**
เอกสารนี้บอกวิธี*ใช้วิจารณญาณ*กับสิ่งที่เขียนเป็นกฎไม่ได้

## คนอ่านที่เขียนให้

นักเทรดไทยตั้งแต่มือใหม่ถึงระดับกลาง (RULES ข้อ 21 — **ไม่เปลี่ยน**)
ศัพท์เทคนิคที่จำเป็นให้ใส่วงเล็บกำกับไทยครั้งแรกครั้งเดียวในบท ·
ศัพท์ที่ผู้อ่านไม่จำเป็นต้องรู้ ไม่ต้องขึ้นบทเลย

## ลำดับอธิบายที่ผู้อ่านตามทัน

เมื่อย่อหน้ามีองค์ประกอบครบ ให้เรียงเป็น:

**ภาพตลาด → หลักฐาน → ความหมายของหลักฐาน → เงื่อนไขหรือความเสี่ยง**

- เริ่มจากสิ่งที่ราคา “กำลังเป็น” ไม่เริ่มด้วยรายชื่อ indicator ยาว ๆ
- บอกหลักฐานก่อนตีความ และผูกแต่ละตัวเลขกับชื่อระดับ/ค่า/กรอบเวลาให้ชัด
- อธิบายความหมายเท่าที่ต้นฉบับสรุปไว้ ห้ามเติมเหตุผลที่ต้นฉบับไม่ได้ยืนยัน
- ปิดด้วย “หาก/ตราบใด/จนกว่า” เมื่อข้อสรุปมีเงื่อนไข ห้ามตัดคำเงื่อนไขเพื่อให้ประโยคสั้น

ถ้าต้องใช้ศัพท์เฉพาะ ให้บอกผลต่อการอ่านตลาดก่อนหรือพร้อมกับศัพท์ เช่น อธิบายว่า
“แรงซื้อชะลอ” สำคัญอย่างไร แล้วจึงกำกับชื่อค่าเมื่อผู้อ่านจำเป็นต้องรู้ ไม่แปลงศัพท์แบบคำต่อคำ
จนแม่นทางภาษาแต่ผิดหน้าที่ทางการเงิน

## เก้าหมวดที่ต้องดูด้วยวิจารณญาณ

| หมวด | สัญญาณที่ต้องจับ |
|---|---|
| `translated_syntax` | ลำดับคำแบบอังกฤษ · ประธานลอย · "ถูก...โดย" ที่ไทยไม่พูด · นามธรรมเป็นประธานยาว ๆ |
| `natural_thai` | อ่านออกเสียงแล้วสะดุด · ต้องย้อนอ่านซ้ำถึงจะรู้ว่าอะไรทำอะไร |
| `internal_language` | ศัพท์ระบบหลุดถึงผู้อ่าน (ชื่อด่าน ชื่อไฟล์ ชื่อกลไก ชื่อค่าเทคนิคดิบ) |
| `technical_term` | ศัพท์ที่ควรใช้คำไทยตามศัพท์กลาง หรือใช้อังกฤษทั้งที่มีคำไทยที่คนใช้จริง |
| `sentence_density` | หลายตรรกะอัดในย่อหน้าเดียว จนตามหาว่า "อะไรเป็นเหตุของอะไร" ไม่ได้ |
| `connector_overuse` | คำเชื่อมซ้อนกันหลายชั้น ("ซึ่งโดยที่...ขณะที่...จึง") |
| `tone_mismatch` | ภาษาพูด สำนวนเปรียบเทียบ หรือคำที่ดราม่าเกินโทนบรรณาธิการการเงิน |
| `financial_semantics` | ใช้ศัพท์ถูกภาษาแต่สลับหน้าที่ทางการเงิน เช่น เรียกแนวต้านว่าเป้าหมาย หรือเรียกความผันผวนว่าทิศทาง |
| `causal_overreach` | เติมเหตุ–ผลที่ต้นฉบับไม่ได้ยืนยัน หรือเปลี่ยน “สอดคล้องกับ” เป็น “ทำให้” |

## เส้นที่ห้ามข้ามเฉพาะของภาษาไทย

การเปลี่ยนคำต้องไม่ทำให้:

1. **เงื่อนไขหาย** — ตัด "หาก" ทิ้งแล้วประโยคกลายเป็นบอกเล่า = เปลี่ยนความหมาย ไม่ใช่กระชับขึ้น
2. **น้ำหนักความมั่นใจขยับ** — "อาจ" → "จะ" หรือ "มีโอกาส" → "ยืนยัน" ผิดเท่าแก้ตัวเลข
3. **ข้อสรุปเทคนิคเปลี่ยน** — "ยังพอได้เปรียบ" ≠ "ได้เปรียบชัดเจน"
4. **ประธาน/กรรมสลับความหมาย** — ภาษาไทยละประธานได้ การเรียบเรียงใหม่จึงสลับผู้กระทำได้ง่าย
5. **ตัวเลขไปผูกกับตัวแปรผิดตัว** — ย้ายวลีแล้ว "20 วัน" ไปเกาะเส้นค่าเฉลี่ยผิดเส้น
6. **ศัพท์ถูกแต่หน้าที่ผิด** — “แนวต้าน” กลายเป็น “เป้าหมาย” หรือ “สัญญาณ” กลายเป็น “คำยืนยัน”
7. **ความสัมพันธ์แรงขึ้น** — “เคลื่อนไหวสอดคล้อง” กลายเป็น “เป็นสาเหตุให้”

ข้อ 4–7 เครื่องจับได้ไม่ครบ — **เป็นหน้าที่ของวิจารณญาณล้วน ๆ**
ทุกครั้งที่ย้ายวลีข้ามอนุประโยค ให้อ่านซ้ำว่า ใครทำอะไร · ตัวเลขเกาะอะไร · กรอบเวลาไหน ·
คำใหม่ทำให้หลักฐานกลายเป็นข้อยืนยันหรือเหตุ–ผลที่แรงกว่าเดิมหรือไม่

## สิ่งที่มัก "ดูเหมือนผิดแต่ถูก"

- **ไม่มีเครื่องหมายจบประโยค** — ปกติของภาษาไทย ห้ามเสนอเติมมหัพภาค
- **เว้นวรรครอบตัวเลข** (`เส้นค่าเฉลี่ย 20 วัน ที่ 4,061`) — เป็นแบบที่ใช้อยู่ ไม่ใช่ช่องว่างเกิน
- **"ในรอบการซื้อขายล่าสุด" ในบทหุ้นสหรัฐช่วงเช้าไทย** — ถูกแล้ว ตลาดเปิด 20:30 น.
- **บทไม่มีหัวข้อแผนเทรด** — วันที่แผนไม่ผ่านเกณฑ์ หัวข้อหายตามสเปก ไม่ใช่บทขาด

## ก่อนเสนอทุกข้อ

1. ระบุ Financial Meaning Map ตามสกิลกลาง: บริบท · สภาวะ · หลักฐาน · ข้อสรุป · เงื่อนไข/ความเสี่ยง
2. ระบุกฎใน `Repo/language/locales/th-TH/` ที่รองรับข้อเสนอ ตอบไม่ได้แปลว่าเป็นรสนิยมส่วนตัว
3. ตรวจว่าถ้าทุกบทถูกแก้แบบนี้ บท A กับ D ยังต่างกันหรือไม่ ถ้าไม่ต่าง แปลว่ากำลังกลืนสไตล์
4. หากต้นฉบับกำกวม ให้คืน `FINANCIAL_MEANING_AMBIGUOUS` ห้ามเดาหรือซ่อมสาระแทนเจ้าของบท
