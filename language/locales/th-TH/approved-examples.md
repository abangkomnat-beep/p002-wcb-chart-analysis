# ตัวอย่างที่ผู้ใช้อนุมัติแล้ว — th-TH

> **ยังว่าง** — baseline อยู่สถานะ `calibrating` และยังไม่มีรอบอนุมัติใดเกิดขึ้น
> ห้ามเติมตัวอย่างที่ผู้ใช้ยังไม่ได้อนุมัติจริงลงไฟล์นี้ ไม่ว่าจะดูดีแค่ไหน
> — ไฟล์นี้คือหลักฐานว่ากฎแต่ละข้อ "มาจากการอนุมัติใด" ถ้าปนของที่แต่งเอง ทั้งแฟ้มก็ใช้อ้างอิงไม่ได้

## กติกาการใช้ไฟล์นี้

ทุกตัวอย่างติด metadata และ **ห้ามคัดลอกประโยคไปใช้ตรงตัว** — ใช้เพื่อให้เข้าใจ *รสนิยมภาษา* เท่านั้น

```
example_id: TH-EX-001
status: approved
approved_at: YYYY-MM-DD
batch_id: <ชุดอนุมัติประจำวันที่ผู้ใช้ตอบ>
revision_id: L-0xx
category: <หมวดใน review_categories>
use_as: style_reference_only
copy_allowed: false
```

## รูปแบบรายการ

```markdown
### TH-EX-001 · natural_thai · อนุมัติ YYYY-MM-DD (batch B-YYYYMMDD)

**เดิม:** <ข้อความต้นฉบับ>

**หลังแก้:** <ข้อความที่ผู้ใช้อนุมัติ>

**เหตุผล:** <ทำไมถึงดีกว่า>

**สิ่งที่ไม่เปลี่ยน:** <ตัวเลข/เงื่อนไข/ระดับความมั่นใจที่ยังเท่าเดิม>
```
