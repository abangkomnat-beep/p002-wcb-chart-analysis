# CHANGELOG — th-TH-financial-analysis

รูปแบบเวอร์ชัน `MAJOR.MINOR.PATCH`

- **PATCH** — คำผิด สะกด เพิ่มตัวอย่างที่ไม่เปลี่ยนแนวทาง ปรับคำอธิบายกฎ
- **MINOR** — เพิ่มกฎศัพท์ เพิ่มรูปการอธิบาย เพิ่มแนวทางเฉพาะสินทรัพย์ เปลี่ยน preference ที่ไม่ทำลายหลักเดิม
- **MAJOR** — เปลี่ยนโทนหลัก เปลี่ยนกลุ่มผู้อ่าน เปลี่ยนแนวการเขียนอย่างมีนัยสำคัญ
