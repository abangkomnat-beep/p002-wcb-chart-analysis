# Style L — Forex Daily Plan Authority

This document is the style-specific human authority for L. It governs the
H4/H1/M30/M15 topology, the public trade plan, conditional invalidation, and
the daily calendar. The generic WCB daily output contract is a parent format
only and cannot be the sole authority for L.

The visual manifest requires `h1_plan`, `m15_trigger`, and `daily_calendar`.
The article, trade-plan QA, timeframe facts, plan state, and visual manifest
must remain bound to the same article.
